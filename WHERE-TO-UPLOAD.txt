Upload these files to your GitHub repository (they replace the old ones with the same name):

  index.html                                   -> main (root) folder of the repo
  netlify/functions/customer-response.js       -> netlify/functions folder   (THIS is the file that adds Groq + OpenRouter)
  netlify/functions/customer.js                -> netlify/functions folder
  netlify/functions/transcribe.js              -> netlify/functions folder
  netlify/functions/lib/common.js              -> netlify/functions/lib folder

Then in Netlify -> Site configuration -> Environment variables add:
  GROQ_API_KEY         (value = your gsk_... key)
  OPENROUTER_API_KEY   (value = your sk-or-... key)   [optional]
and run Deploys -> Trigger deploy -> Deploy site.

Check: open  https://YOUR-SITE.netlify.app/.netlify/functions/customer-response
The text must contain "groq" and "openrouter". When a key is set you will see "configured":true next to it.
